# Hybrid Deep Learning and Handcrafted Features for Tomato Plant Disease Classification and Severity Estimation
This repository contains code for tomato leaf disease classification using CNN, HSV features, autoencoder, and attention mechanism.

# Description
Implementation of EfficientNetB0 + HSV handcrafted features for tomato disease classification and severity estimation.

# Dataset Information
PlantVillage Tomato Leaf Dataset
https://www.kaggle.com/datasets/kaustubhb999/tomatoleaf

# Requirements
Python 3.10
TensorFlow 2.15
OpenCV
Scikit-learn
NumPy
Matplotlib
Seaborn

# Usage
1. Download dataset
2. Place dataset in dataset/ folder
3. Run preprocessing.py
4. Run train.py
5. Run evaluate.py

# Output
Classification accuracy
Precision
Recall
F1-score
Disease severity estimation
