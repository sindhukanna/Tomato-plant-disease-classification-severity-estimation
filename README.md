# Tomato Leaf Disease Detection using Hybrid CNN Model

This repository contains code for tomato leaf disease classification using CNN, HSV features, autoencoder, and attention mechanism.

## Dataset
The dataset used is publicly available:
https://www.kaggle.com/datasets/kaustubhb999/tomatoleaf

## Requirements
- Python 3.8+
- TensorFlow / PyTorch
- OpenCV
- NumPy

## Usage
Run the main script to train and test the model.

## Note
Due to dataset size, raw images are not uploaded here. Please download from Kaggle link above.
